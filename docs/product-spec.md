# 製品仕様

## 目的

Nousarium は、対話を知識へ変換し続ける個人用ナレッジ OS です。チャットそのものが目的ではなく、思想・技術・プロジェクトを一つの Obsidian Vault に育てることが目的です。

## 利用者

- 単一ユーザー
- Tailscale の tailnet 内からのみアクセス
- 到達制御は Tailscale。アプリは Bearer トークンで agent-service と通信する

## 中心フロー

1. スマホまたは PC で会話を始める
2. 発言のたびに AI が、即答か深掘りか調べ物かを判断する
3. 必要なときだけ Vault を検索し、既存ノートを参照する
4. 残す価値があると判断したらノートを作成または更新する
5. 対話全文はシステムが Journal に追記する
6. 書き込みは Git に記録され、差分と復元ができる

用途の指定やノート案の確認は不要です。判断とファイル編集は Cursor に任せます。規約は Vault の `AGENTS.md` と `.cursor/rules` にあります。

## アクセス権限

| 値 | できること |
| --- | --- |
| `vault`（既定） | Vault の参照と更新。判断は AI |
| `chat` | テキスト応答のみ。Vault には触れない |

権限は Run 開始時に固定します。実行中の昇格はしません。変更は次の送信から適用します。安全は事前の細かい権限分けではなく、Run 単位の Git コミットと取り消しで担保します。

## ノート

AI が既存ノートを探し、あれば更新し、なければ `Notes/` に作ります。分類が決まらないものは `status: seed` のまま置きます。ひとつの会話で扱っている主題は、同じノートを育てます。

`status: stable` の本文変更は、規約上 AI が自動では行いません。

## 対話ログ

会話の全文は Vault の `Journal/Conversations/` に Markdown として永久保存します。追記は Nousarium が行い、AI は書き換えません。runtime の SQLite は会話一覧、Agent ID、権限スナップショット、Run 状態のための作業用索引です。

| 操作 | 挙動 |
| --- | --- |
| 通常の検索除外 | `ai_access: excluded`。`.cursorignore` に載せ、AI から隠す |
| 保護領域 | `_protected/`。Agent が読めない |
| 通常削除 | `Trash/` へ移動。Git から復元できる |
| 手動完全削除 | 明示確認が必要 |

## 同時編集

Web エディター、Obsidian、AI が同じファイルを触る場合があります。保存時に読み込み時ハッシュと現在ハッシュを比較し、不一致なら上書きせず差分確認へ進みます。書き込み Run は Vault 単位で同時に 1 件です。

## 対象外

- 複数ユーザー
- インターネットへの直接公開
- 音声入力
- 意味検索
- 共同編集 CRDT
- 完全 WYSIWYG
- Vault の自動リモート作成
- 完全削除の履歴抹消

## 受入条件

- 公開システム Repo に個人データが入らない
- 新規非公開 Vault を初期化できる（`AGENTS.md` と `.cursor/rules` を含む）
- スマホから会話し、Vault 更新の可否を切り替えられる
- AI が Vault を検索し、ノートを作成・更新できる
- 競合時に黙って上書きされない
- 書き込み Run を Git から確認・復元できる
- Cursor SDK、Markdown Editor、Vault 実装を Port 単位で交換できる
