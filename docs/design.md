# UI 設計

値の正本は [packages/ui/src/styles.css](../packages/ui/src/styles.css) の `@theme` です。この文書は意味と使い方を定めます。

## 原則

- モバイルファースト。片手で送信・権限変更・ノート確認ができる
- チャットを主画面にし、編集と差分は必要なときだけ前面に出す
- 現在のモードと権限を常時表示する
- 状態（生成中、失敗、競合、復元可能）を色と文言で区別する
- 装飾より可読性。大きな見出し、十分な行間、低い視覚ノイズ

## 画面

| 画面 | 用途 |
| --- | --- |
| 会話一覧 | 最近の対話、新規作成 |
| チャット | メッセージ、ストリーム、入力 |
| ノート確認 | 新規ノート案の保存先と本文 |
| ファイル | Vault ツリー、検索、プレビュー / 編集 |
| 変更履歴 | Run 単位の差分と復元 |

スマホではチャットを全幅にし、ファイルと履歴はシートまたは別ルートにします。PC ではチャットとプレビューを横並びにできます。

## チャット

- ユーザーとアシスタントを左右ではなく、役割ラベルと余白で区別する
- ストリーム中は本文を逐次追加し、ツール実行は折りたたみ行にする
- 停止ボタンは生成中のみ表示する
- 失敗時は原因と再送を同じ吹き出しの下に置く
- 参照したノートは `[[Wikilink]]` としてタップ可能にする

## モードと権限

チャットヘッダーに 2 つのセレクターを置きます。

- モード: 検討 / 実行（内部値 `plan` / `agent`）
- 権限: 会話 / 参照 / Vault作業（内部値 `chat` / `read` / `vault-work`）

生成中に変更すると「次の送信から適用」と表示します。即時適用が必要なら停止して再送します。

## Markdown

- 原文編集とプレビューを分ける。完全なライブプレビューは行わない
- エディター実装（CodeMirror）の型は `MarkdownEditor` の外に出さない
- YAML Frontmatter は折りたたみ可能な Properties 領域として見せる
- `[[Wikilink]]` と `#分野/...` はプレビューでリンク / チップにする

## 差分と競合

- 追加は accent、削除は danger トークン
- Run 単位の要約（何ファイル、何行）を先に見せ、詳細 diff は展開する
- 競合時は「自分 / AI / ディスク」を並べ、採用操作を明示する
- 破壊的な復元はボタン文言を「この Run の変更を取り消す」にする

## トークン

| 役割 | 使い方 |
| --- | --- |
| `surface` | ページ背景 |
| `surface-elevated` | カード、入力、シート |
| `text-primary` | 本文 |
| `text-secondary` | 補助 |
| `accent` | 主操作、ストリーム中 |
| `danger` | 失敗、削除、競合 |
| `warning` | 権限変更の保留、要確認 |
| `success` | 保存完了、復元完了 |

余白は 8 の倍数。角丸は入力とカードで揃え、チャット吹き出しだけ少し大きくします。

## アクセシビリティ

- タップ領域は 44px 以上
- フォーカスリングを消さない
- 生成中は `aria-live="polite"`
- 色だけに依存しない（アイコンまたは文言を添える）
- 入力欄はソフトウェアキーボード表示時も送信できるように固定する

## 使わないもの

- 絵文字をアイコン代わりにする
- 強いグラデーション
- 画面ごとの別配色
- 権限を隠したフローティング操作
